nownab.log
==========

https://blog.nownabe.com/

## Prerequisites

- [mise](https://mise.jdx.dev/)

## Setup

```sh
mise run setup
```

## Writing

```sh
mise run server        # dev server
mise run new <slug>    # create content/<slug>.md and static/images/<slug>/
mise run lint          # textlint
mise run build         # build into public/
```
