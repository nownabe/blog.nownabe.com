ついこないだまで OSS 活動にあんまり興味がなかった。
必要がなければ他人のコードも読まないし、自分のコードは自分で建てた Git サーバにプッシュしてました。

ところが Github を使うようになり、OSS 活動っぽいことをやってみるとこれがとても楽しい。
他の人のコードを読むのはとても勉強になるし、自分のやったことが目に見えるのがイイ。

インプット→アウトプットのサイクルがいい感じで回ってるような気がします。

まだまだ初心者なんで、そのうち有名な OSS に貢献したりとかしてみたいですね。
もっというと有名な OSS 作ってみたいです w
