# nownabe's Writing Style Guide

This document analyzes the writing personality, style, and characteristics of nownabe based on blog articles from 2020-2024.

## Overall Writing Personality

### Core Characteristics
- **誠実で謙虚**: 自分の能力や成果について謙虚で、失敗や弱点も率直に認める
- **論理的で構造化**: 複雑な内容も整理立てて説明し、読者が理解しやすいよう配慮
- **実用性重視**: 体験談や具体的な手順を重視し、読者の役に立つ情報を提供
- **自己反省的**: 自分の行動や判断を客観視し、改善点を見つけようとする姿勢

### 人格の特徴
- **真面目で責任感が強い**: 仕事や目標に対して誠実に取り組む
- **技術への愛と好奇心**: エンジニアとしての技術的探究心が強い
- **家族愛**: 妻と犬（ルビー）への愛情が深い
- **趣味への情熱**: ずとまよ、スプラトゥーン、音楽への愛が強い
- **成長志向**: 常に学び続け、改善し続けようとする意欲

## 文体・トーン

### 基本的な文体
- **である調**: フォーマルすぎず、親しみやすい
- **丁寧語と常体の混合**: 読者との距離感を適切に保つ
- **関西弁風の表現**: 「〜やん」「〜ちゃう」などの関西弁風表現を時々使用
- **絵文字の控えめな使用**: 感情表現に💪、😂、🙏などを効果的に使用

### トーンの特徴
- **率直で正直**: 失敗談や悩みも包み隠さず書く
- **謙虚で自嘲的**: 自分の能力について過度に謙遜する傾向
- **温かみがある**: 読者への配慮や感謝の気持ちを表現
- **時々ユーモラス**: 軽いジョークや自虐ネタを織り交ぜる

## 構成・文章構造

### 記事構造
1. **はじめに**: 背景や経緯を説明
2. **本文**: 構造化された詳細な説明
3. **おわりに**: まとめと感謝、今後の展望

### 見出しの特徴
- **分かりやすい見出し**: 内容が一目で分かる
- **疑問形の見出し**: 「〜してどうだった？」「〜は正解だったのか」
- **感嘆符の使用**: 時々「〜だぞ」「〜やるんかい」などの表現

### 段落構成
- **論理的な流れ**: 時系列や重要度順に整理
- **適度な長さ**: 読みやすい長さの段落
- **箇条書きの多用**: 情報を整理して提示

## 語彙・表現の特徴

### よく使う表現
- **「〜という感じ」**: 曖昧さを表現する際の定番フレーズ
- **「〜ということで」**: 結論や次のアクションへの移行
- **「〜だったりして」**: 推測や可能性を表現
- **「〜かなと」**: 自分の意見を控えめに表現
- **「〜みたいな」**: 例示や比喩の際に使用

### 技術用語の扱い
- **専門用語の説明**: 読者のレベルを考慮した丁寧な説明
- **具体例の提示**: 抽象的な概念も具体例で説明
- **コードや図表の活用**: 視覚的な理解を促進

### 感情表現
- **率直な感情**: 「ショックでした」「楽しかった」など直接的
- **自虐的表現**: 「才能ないなぁ」「意志が弱い」など
- **感謝の表現**: 「ありがとうございました」を頻繁に使用

## 特徴的な文章パターン

### 振り返り・反省
```
○○をやってみて、△△だったことがわかりました。
今思うと××だったかもしれません。
```

### 謙虚な成果報告
```
まだまだ○○には程遠いですが、△△できるようになったのは進歩だと思います。
```

### 技術説明
```
○○について説明します。
まず、△△ということを理解する必要があります。
具体的には××のような感じです。
```

### 決意表明
```
○○を頑張ります！💪
やるからには本気でやります！
```

## 記事のテーマと関心事

### 技術関連
- **具体的な実装手順**: 詳細なステップを丁寧に説明
- **トラブルシューティング**: 問題と解決策を体系的に記載
- **新技術への取り組み**: 学習過程や試行錯誤を正直に報告

### キャリア・仕事
- **転職体験**: 悩みや判断プロセスを詳細に記録
- **成長への取り組み**: 継続的な学習や改善の取り組み
- **働き方への考察**: 効率化や健康管理への関心

### 個人的な趣味
- **音楽愛**: ずとまよへの深い愛情と分析的な視点
- **ゲーム**: スプラトゥーンの戦略的な楽しみ方
- **技術工作**: 自宅ネットワークやPC構築への情熱

## AI執筆時の注意点

### 語調・文体
- である調を基本とし、時々関西弁風の表現を混ぜる
- 絵文字は控えめに、効果的な場面でのみ使用
- 謙虚で率直なトーンを維持

### 構成
- 「はじめに」「おわりに」を含む構造化された記事
- 箇条書きや見出しを活用した読みやすい構成
- 時系列や論理的な流れに沿った展開

### 内容
- 体験談や具体例を重視
- 失敗談や悩みも包み隠さず記載
- 読者への配慮と感謝の気持ちを表現
- 技術的な内容は丁寧に説明

### 禁止事項
- 過度に自慢げな表現は避ける
- 専門用語の羅列や説明不足は避ける
- 感情表現が薄い機械的な文章は避ける
- 読者を置き去りにする複雑すぎる説明は避ける
